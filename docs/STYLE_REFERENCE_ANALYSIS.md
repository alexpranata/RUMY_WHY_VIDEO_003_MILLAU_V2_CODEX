# Aesthetic reference study — user-supplied Mississippi engineering clip

The clip is provided as a visual-inspiration reference only and MUST NOT become output footage. Frame sampling revealed a mixed documentary visual language rather than a single perpetual CGI flyover:

- Quick readable drone/aerial contextual views of a dam or landscape.
- Bright high-key 3D terrain dioramas, stylized cutaway civil-engineering models, water-flow visualization.
- Worker/industrial reenactment close-ups (tools, cut/ditch, labor), often with tactile visible action.
- Editorial maps and diagrams that explain transitions between location, time and mechanisms.
- Large animated numerals, pointer/circles/arrows, and clear subtitle hierarchy.

For Millau, imitate that **visual grammar**, not its exact footage or graphics:

1. Start with an engineering question, then alternate **detail / mechanical action / large-scale context**.
2. On-screen 'what changes physically' each 3–5sec. At least 60% of meaningful screen-time should explain building, not hero shots.
3. Daylight vivid realistic French limestone, vibrant green valley, bright blue sky; clean warm-white/neutral rendering. Avoid overcooked oversaturation or black shadow detail.
4. Visual actions: drilling rig rotating, red hydraulic formwork climbing, welder fusing seam, hydraulic translator cycling, deck creeping above a red tower, mast rotating up.
5. Camera moves serve each action: side track relative to moving machine, pass-through industrial site, tight orbital around cutaway, guard-railed worker-level view; avoid zoom for its own sake.
6. Descriptive final AI shots should have **no baked-in type, arrows or subtitles**. Build RUMY WHY graphics and text in Codex with yellow `#FFD400`, white caption text and safe zones.
